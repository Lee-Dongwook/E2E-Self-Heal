# محرك الشفاء الذاتي لاختبارات E2E المدعوم بالذكاء الاصطناعي

**العربية** · [English](README.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md)

محرك **الشفاء الذاتي** الذي يصلح تلقائياً اختبارات **Playwright** المعطلة باستخدام **وكيل ذكاء اصطناعي** مبني على **LangGraph**.

عندما يؤدي تغيير في واجهة المستخدم إلى إعادة تسمية أو إعادة هيكلة عنصر وينكسر محدد الاختبار، يقوم المحرك بتشخيص الفشل، وتصحيح المحدد/الانتظار المعطل، و **التحقق من المحدد الجديد مقابل DOM المباشر**، ثم إعادة تشغيل الاختبار حتى ينجح (أو حتى الوصول إلى حد إعادة المحاولة) وكتابة الإصلاح مرة أخرى - كـ **CLI** محلي أو **إجراء GitHub Action للـ CI** يفتح PR للإصلاح.

> **حاجز النطاق:** المحرك يصلح فقط **محددات المواقع الفاشلة وشروط الانتظار**. لا يمس أبداً التأكيدات أو منطق الاختبار، وكل تصحيح يظل قابلاً للمراجعة البشرية.

## المشكلة

تقوم بشحن تغيير في المكون. يتم إعادة تسمية `className`، أو يتغير `id` زر، أو يتحرك غلاف `<div>`. لا يوجد شيء *خاطئ* - لكن محدد Playwright في مكان ما لم يعد يتطابق، ويتحول خط الأنابيب إلى اللون الأحمر.

## ماذا يفعل

يصلح محددًا واحدًا أعيدت تسميته تلقائياً - **ولا يمس أي شيء آخر في الاختبار**.
